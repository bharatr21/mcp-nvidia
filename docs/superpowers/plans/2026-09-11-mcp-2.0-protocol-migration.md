# MCP 2.0 Protocol Migration (Plan A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate `mcp-nvidia` from the `mcp` 1.x SDK to `mcp` 2.2.0 so the server speaks the `2026-07-28` protocol over Streamable HTTP at `/mcp`, while still serving 2025-era clients, and ship it as 1.0.0.

**Architecture:** Handlers move from decorators to `Server(...)` constructor keyword arguments with `(ctx, params)` signatures returning typed result models. `http_server.py` is rebuilt around `Server.streamable_http_app()` mounted under the existing host Starlette app, which keeps the module attribute `http_app` that the Dockerfile boots. Both protocol eras are served from the one `/mcp` endpoint by the SDK's dual-era dispatcher, so there is no shim code.

**Tech Stack:** Python 3.10+, `mcp` 2.2.0, `mcp-types` 2.2.0, Starlette 1.x, uvicorn, httpx2 (transitive, used by tests), pytest + pytest-asyncio (`asyncio_mode = "auto"`), hatchling, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-02-mcp-2.0-migration-design.md`

## Scope

This plan covers spec Stages 1, 2, 3 and 5. **Stage 4 (MCP Apps, replacing `mcp-ui-server`) is deliberately excluded** and becomes Plan B, per the spec's own risk table which notes Stage 4 is independent and can follow.

Two deviations from the spec text, both decided during planning:

1. **The `/ui/*` HTMX routes stay.** Spec Stage 2 removes them because Decision 6 makes them consumerless — but Decision 6 is Stage 4, which is Plan B. Removing them here would delete working behaviour before its replacement exists. Plan B removes them together with the server-side renderer.
2. **`mcp-ui-server` stays, guarded.** `build_tool_result_with_ui()` already wraps its import in `try/except ImportError` and falls back to `build_tool_result()`. It is left alone; Plan B deletes it.

Publishing is out of scope. This plan ends with a green suite, updated docs and version numbers on the branch. Tagging, PyPI/npm upload and the Railway deploy stay manual.

**Start from the latest `main`.** Before Task 1, merge `main` into `mcp2` so the migration starts from the most recent released code. No task in this plan changes search or ranking. Anything that arrives through that merge is not this plan's edit: the "do not touch `_get_tool_schemas()`" constraint below covers this plan's own changes only.

## Global Constraints

Every task's requirements implicitly include these. Exact values, copied from the spec and from verification against the installed SDK:

- Runtime dependency floor: `mcp>=2.2.0,<3`. Not 2.0.0 — 2.1.0 fixed HTTP `202` notification acks and stopped leaking cache-hint fields to pre-2026 clients, both of which the dual-era tests exercise.
- `starlette>=1.3.0`, `requires-python = ">=3.10"` (unchanged).
- Modern protocol version: `2026-07-28`. Handshake-era versions still served: `2024-11-05`, `2025-03-26`, `2025-06-18`, `2025-11-25`.
- Cache hints, on `tools/list`, `resources/list` and `resources/read` only: `ttl_ms=3_600_000`, `scope="public"`. The SDK default is `ttl_ms=0`, `scope="private"`, which is wrong for this server's static listings.
- Unknown or malformed resource URI raises `MCPError(code=INVALID_PARAMS, ...)` → `-32602`. A bare `ValueError` would reach clients as a generic `-32603 "Internal server error"`.
- MCP endpoint path: `/mcp`. `/sse` and `/sse/messages` return `410` with body `{"error": ..., "moved_to": "/mcp"}`.
- **`mcp_nvidia.http_server:http_app` must keep that exact module attribute name** — the Dockerfile's `CMD` boots it directly with uvicorn, bypassing `run_http_server()`. The MCP session-manager lifespan must therefore be attached to `http_app` itself.
- Do not touch `_get_tool_schemas()`, `_get_tool_definitions()`, `_generate_sdk_files()` or anything under `sdk_generator/`. The schemas keep their camelCase `"inputSchema"` keys.
- Verified 2026-09-10: 2.x models still accept camelCase constructor kwargs via aliases (`Tool(**{"inputSchema": ...})`, `Resource(mimeType=...)`, `CallToolResult(structuredContent=..., isError=...)`). Reading a field *off* an object requires the snake_case name (`result.structured_content`).
- **Never put `Client(...)` or an app lifespan in an async yield fixture.** Verified 2026-09-11: pytest-asyncio runs fixture setup and teardown in *different tasks*, and both open anyio cancel scopes, so every such fixture fails teardown with `RuntimeError: Attempted to exit cancel scope in a different task than it was entered in`. The tests pass and then error. Enter these with `async with` **inside the test body** instead, so the scope opens and closes in one task. Every test below is written that way; do not "tidy" them into fixtures.
- Tests address the app as `http://127.0.0.1:8000`, which matches the `127.0.0.1:*` allow-list entry. A `Host` the allow-list does not cover gets `421`, so a base URL like `http://testserver` silently breaks every HTTP test.
- **Backward compatibility: preserve by default, break for simplicity.** 1.0.0 is already breaking, so the test for each individual break is whether it buys simplicity. Keep compatibility that is free — dual-era protocol support costs zero shim code, so it stays. Break it where preserving it would mean a shim, a compatibility branch, a second code path, or a dependency we would otherwise drop. Never break silently: anything dropped is named in the CHANGELOG entry and the README notice, with its replacement. See the spec's "Backward compatibility" section.
- **Test at the protocol layer, not the handler.** Calling a handler directly with hand-built Python arguments proves nothing about what real clients get, and a fully green suite can hide a crash that every real client hits. Any test asserting request/response behaviour goes through an in-memory `Client` or an HTTP request.
- **Tests must not assert result order or specific `relevance_score` values.** Ranking is outside this migration, and a test that pins order would break for reasons unrelated to it.

```python
async def read_resource(ctx, params: ReadResourceRequestParams) -> ReadResourceResult:
    """Read SDK resource by URI."""
    uri = str(params.uri)
    logger.info(f"Reading resource: {uri}")

    if not uri.startswith("mcp-nvidia://sdk/"):
        raise ValueError(f"Invalid resource URI: {uri}")

    parts = uri.replace("mcp-nvidia://sdk/", "").split("/")
    if len(parts) != 2:
        raise ValueError(f"Invalid resource URI format: {uri}")

    language, filename = parts

    if language not in ["typescript", "python"]:
        raise ValueError(f"Unknown SDK language: {language}")

    sdk_files = _sdk_files_cache

    if filename not in sdk_files[language]:
        raise ValueError(f"SDK file not found: {filename}")

    content = sdk_files[language][filename]
    logger.info(f"Successfully read resource {uri} ({len(content)} bytes)")

    mime_type = "text/plain" if filename.endswith(".md") else ("text/x-python" if language == "python" else "text/typescript")
    return ReadResourceResult(contents=[TextResourceContents(uri=uri, mimeType=mime_type, text=content)])
```

"""Conformance tests for the 2026-07-28 protocol surface."""

import contextlib

import httpx2
import pytest

from mcp_nvidia.http_server import create_http_app

MODERN_HEADERS = {
    "Accept": "application/json, text/event-stream",
    "MCP-Protocol-Version": "2026-07-28",
}

# The modern envelope requires these _meta keys; omitting clientCapabilities is a -32602.
MODERN_META = {
    "io.modelcontextprotocol/protocolVersion": "2026-07-28",
    "io.modelcontextprotocol/clientInfo": {"name": "conformance-test", "version": "1.0"},
    "io.modelcontextprotocol/clientCapabilities": {},
}


@contextlib.asynccontextmanager
async def http_client():
    """Drive a real host app in-process, through its real lifespan.

    This is a helper entered with `async with` inside each test, NOT a fixture:
    pytest-asyncio tears fixtures down in a different task than it sets them up
    in, which breaks the anyio cancel scope the session manager opens.

    Each call builds a fresh app because a session manager can only be run once
    per instance. The base URL must match the Host allow-list or every call 421s.
    """
    app = create_http_app()
    async with app.router.lifespan_context(app):
        transport = httpx2.ASGITransport(app=app)
        async with httpx2.AsyncClient(transport=transport, base_url="http://127.0.0.1:8000") as client:
            yield client


def modern_request(method: str, request_id: int = 1, **params):
    return {
        "jsonrpc": "2.0",
        "id": request_id,
        "method": method,
        "params": {"_meta": MODERN_META, **params},
    }


async def test_mcp_endpoint_serves_modern_tools_list():
    """A 2026-07-28 client gets tools from /mcp."""
    async with http_client() as client:
        response = await client.post(
            "/mcp",
            json=modern_request("tools/list"),
            headers={**MODERN_HEADERS, "Mcp-Method": "tools/list"},
        )

    assert response.status_code == 200
    result = response.json()["result"]
    assert [t["name"] for t in result["tools"]]


async def test_listings_are_publicly_cacheable():
    """Guards the SDK's private/zero-TTL default."""
    async with http_client() as client:
        response = await client.post(
            "/mcp",
            json=modern_request("tools/list"),
            headers={**MODERN_HEADERS, "Mcp-Method": "tools/list"},
        )

    result = response.json()["result"]
    assert result["ttlMs"] == 3_600_000
    assert result["cacheScope"] == "public"


async def test_header_body_mismatch_is_rejected():

def _build_transport_security() -> TransportSecuritySettings:
    """Build the DNS-rebinding allow-list.

    `streamable_http_app(host=...)` is a security setting, not a bind address: left at
    its default the SDK accepts only loopback Host headers, which rejects every request
    that arrives through Railway's public hostname. Railway injects RAILWAY_PUBLIC_DOMAIN;
    MCP_ALLOWED_HOSTS (comma-separated) covers any other deployment.
    """
    allowed_hosts = ["127.0.0.1:*", "localhost:*", "[::1]:*"]
    allowed_origins: list[str] = []

    for domain in (os.getenv("RAILWAY_PUBLIC_DOMAIN", ""), *os.getenv("MCP_ALLOWED_HOSTS", "").split(",")):
        domain = domain.strip()
        if domain:
            allowed_hosts.append(domain)
            allowed_origins.append(f"https://{domain}")

    return TransportSecuritySettings(
        enable_dns_rebinding_protection=True,
        allowed_hosts=allowed_hosts,
        allowed_origins=allowed_origins,
    )
